# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to `support@maxisappai.com`. Do not include credentials, customer information, system addresses, configuration exports, or unredacted logs in a public issue.

Include the affected REXLiTE integration version, Home Assistant installation type and version, architecture, reproduction steps, and sanitized log timestamps. REXLiTE will acknowledge the report, assess its severity, and coordinate a fixed release before public disclosure.

If any credential may have been exposed, revoke or rotate it immediately. Disabling or removing the integration alone does not invalidate exposed credentials.

Security updates are distributed as GitHub Releases through HACS. Users should keep the HACS integration current and run the newest stable release.
